## Сборка и запуск проекта
В корневой папке проекта нужно запустить скрипт:
```
mkdir -p build && cd build
cmake ..
cmake --build .
./app
cd ..
```
## Сборка проекта
В корневой папке проекта нужно запустить скрипт:
```
mkdir -p build && cd build
cmake ..
cmake --build .
cd ..
```
## Запуск проекта 
В корневой папке проекта нужно запустить скрипт:
```
cd build && ./app
cd ..
```
